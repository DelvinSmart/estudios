# Tema 12: Cómo hice Estudios Bíblicos

Cómo se construyó, el 12 y 13 de noviembre de 2026, la página **Estudios Bíblicos**: un sitio donde cada estudio de la Biblia se ve como un mapa, se descarga en PDF y se edita desde un panel propio.

- Página: https://delvinsmart.github.io/estudios-biblicos/
- Panel: https://delvinsmart.github.io/estudios-biblicos/panel.html
- Código: `SSD_Desarrollo/Developer/estudios-biblicos` (y en GitHub: `DelvinSmart/estudios-biblicos`)

| Archivo | Para qué sirve |
|---|---|
| [LECCION.md](LECCION.md) | La clase: la arquitectura, cada archivo, cómo se conectan, los colores, la publicación y el panel. Con ejercicios y respuestas al final. |
| [EXPLICACIONES-PARA-ENTREVISTA.md](EXPLICACIONES-PARA-ENTREVISTA.md) | Cómo explicar el proyecto en una entrevista, en pocas frases, y las decisiones que se tomaron. |

**Cómo usarlo:** lee la lección una parte por día. Abre el archivo del que habla cada parte y míralo mientras lees. Responde las preguntas sin mirar las respuestas.

**Antes de empezar:** ayuda haber hecho el [Tema 01](../01-leer-codigo/LECCION.md) (leer código), el [Tema 06](../06-git/LECCION.md) (Git) y el [Tema 10](../10-arquitectura/LECCION.md) (arquitectura). Este proyecto es más simple que Copiloto: no tiene React ni Firebase, solo HTML, CSS y JavaScript.
