# Tema 13: Cómo hice la web de Copiloto Driver

Cómo se construyó, del 13 al 14 de noviembre de 2026, la **página web de Copiloto Driver**: el mismo app, pero en la computadora. La persona entra con la misma cuenta del teléfono y ve sus ganancias, gastos, combustible, San y Mi cartera en una sola pantalla.

- Código: `SSD_Desarrollo/Developer/copiloto-driver/webapp`
- Para verla en la Mac: `cd webapp && npm run dev` y abrir `http://localhost:5180`
- Para verla con datos de ejemplo (sin entrar): `http://localhost:5180/?demo`
